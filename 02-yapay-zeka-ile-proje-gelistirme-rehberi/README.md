# 02 · Yapay Zeka ile Proje Geliştirme Rehberi

Sitede: [https://fbsoftwaresolutions.com.tr/courses/yapay-zeka-ile-proje-gelistirme-rehberi/](https://fbsoftwaresolutions.com.tr/courses/yapay-zeka-ile-proje-gelistirme-rehberi/)

Bu seride, yapay zeka ile bir projeye başlamadan önce doğru planlama yapmayı ve projeyi adım adım nasıl
geliştirebileceğinizi gösteriyorum. Mind Map kullanımından proje yapısına, doğru prompt hazırlamadan ChatGPT ve
Claude ile çalışmaya, web sitesi geliştirmeden AI Coding süreçlerine kadar kullandığım yöntemleri uygulamalı olarak
paylaşıyorum. Amacımız sadece yapay zekaya kod yazdırmak değil; tekrar kullanılabilir, düzenli ve kontrol edilebilir
bir proje geliştirme sistemi oluşturmak.
